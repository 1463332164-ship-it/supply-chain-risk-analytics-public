库存风险与补货核查

缺口看每日余额，补货看窗口总量与安全缓冲。“预测期无缺口”表示后台首次缺口日为 null；第 0 天表示快照已有缺口。最大净缺口为 0 表示输出的净缺口量为零；建议补货为 0 表示当前规则未建议新增采购，不代表每天都无缺口；预计采购额为 0 是建议量 × 单价的结果，不是金额缺失。所有判断仅适用于当前情景与预测窗口。
